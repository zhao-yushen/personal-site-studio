# 交互实现

只读取与当前组件有关的部分。这些是曾经在真实页面出现的故障模式，不是所有网站都要实现的功能清单。

## 状态与路由

项目 ID、阅读模式、选中标签与背景主题应来自一致状态。深链接、站内选择、进入完整案例和返回时走同一更新路径；避免事件互相触发造成循环。

同页导航先规范化当前路由与目标路由，包括站点根路径、`index.html`、尾斜杠和实际部署子路径。保留复制链接与浏览器后退的语义。返回页面后检查当前作品和可见面板是否匹配。

在 `pagehide` 中拆除观察器或监听器时，如果页面可能进入浏览器返回缓存，应在 `pageshow` 的持久恢复路径重新启用。可重复初始化的模块要幂等，销毁要清理对应资源。

## 动效生命周期

把装饰性连续动画、状态变化与必要界面显示分别管理：

- 文档隐藏、区域离屏或静态模式下暂停不必要的连续绘制。
- 模态框、菜单和反馈即使在全局暂停时也要达到完整可见的终态。
- 不能把打开的弹窗暂停在 `opacity: 0` 的入场帧；减弱动态时直接显示终态。
- 根据操作与内容选取动画强度；避免在所有滚动或点击时重播大型转场。
- WebGL 对纹理、几何体、事件和画布生命周期进行清理。分辨率、粒子和后处理按实际渲染情况调整。

性能观察需说明浏览器、尺寸和硬件范围。CPU 提交时间、帧间隔和 GPU 完成时间不同；不要将局部测量包装成所有设备的保证。

## 键盘与焦点

原生按钮、链接和对话框优先。对话框打开时焦点进入合适控件，关闭时返回仍可见、可聚焦的发起控件；背景不应继续响应被遮住的操作。

浏览器可能先用 Escape 清空原生搜索框。若界面承诺 Escape 关闭弹窗，实际验证非空输入时的按键行为，避免一次按键的行为与提示不符。

章节跳转需要焦点时，可给目的地临时 `tabindex=-1`；聚焦后不要立即删除导致焦点回到 body。失焦时恢复原值，并在导出或销毁时清理临时属性。

快捷键应避开输入框、编辑状态与其他模态交互。不要新增与浏览器、辅助工具或既有产品操作冲突的快捷键。

## 交互图表与模型

输入、结果、表格、标记和解释共用一个计算模型。分别处理有效值、边界、负值、不可达和缺失情况。图的颜色、示意线与数据各自的含义要清楚。

指针坐标使用当前画布/SVG的实际变换和边界；边缘可能出现亚像素误差，可容忍很小的坐标偏差并限制最终值。键盘与指针应能选择同一范围。

展示“最低”“不低于”等阈值时，舍入方向要符合措辞。独立核算模型、验证边界两侧行为，再确认图像与结果一致。合成教学情景应写明假设，不赋予未经估计的需求、概率或因果解释。

## HTML 编辑与导出

仅在已有或请求的编辑、导出能力中使用此部分。

导出基于源内容和可持久化的用户修改。生成的桌面组件、模态框、临时选中类、焦点属性与 `inert` 不应成为重复挂载或锁定页面的来源。

对于启动时生成的组件，导出前去掉生成节点及其瞬时状态，重开后只初始化一次。持久状态应通过明确的数据结构恢复。若现有框架使用其他可靠方法，沿用它。

实际导出并重新打开一次，验证所改组件、编辑内容和路径可用。普通网站不因使用此 skill 自动获得单文件导出要求。
